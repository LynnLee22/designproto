# IoT 조명 웹앱 기본 프레임

기울기 조명 Tilt MONO의 웹, 스마트폰 화면이다. 검은 바탕 정가운데에 센서값에 반응하는 흰 원이 있다. 데이터 흐름: MPU-6050 기울기 센서 → Arduino UNO → USB 시리얼(upload.py) → Supabase `Reading` 테이블 → 이 웹앱.
이 문서 하나에 모든 규칙이 있다. 아래 Setup, Tokens, styles, 컴포넌트 섹션을 모두 따른다.

## 반드시 지킬 시각 규칙

1. **텍스트는 페이지 바탕(`--surface`) 위에 바로 놓는다.** 배경색 있는 사각 박스 위에 글자를 올리는 건 버튼만 허용. 카드 UI를 만들지 않는다.
2. **사각 프레임에 테두리 금지.** border, outline 장식, ring 클래스 모두. (키보드 포커스 링만 예외)
3. **사각 프레임에 라운드 금지.** 버튼, 입력창, 막대 등 사각 요소는 `border-radius: 0` (rounded-* 클래스 금지). 센서 오브제 `.sensor-orb`만 원형이며 상태 점은 8×8 사각이다.
4. **무의미한 소제목 금지.** 내용이 이미 말하는 것을 반복하는 섹션 제목("조명 상태", "컨트롤", "실시간 센서값", "제품 소개" 같은), 제목 위 작은 장식 라벨을 달지 않는다. 컨트롤 이름("센서", "LED")만 쓴다. 섹션 이름은 `aria-label`로.
5. **중점(·) 금지.** 나열은 쉼표나 줄바꿈으로.
6. **자간, 행간은 폰트 기본값.** `letter-spacing`, `line-height`를 지정하지 않는다 (tracking-*, leading-* 클래스 금지). 대문자 라벨(uppercase) 금지.
7. 색, 크기, 간격은 Tokens의 CSS 변수만. 센서 원은 흰색 채움 투명도를 밝기값으로 조절하는 예외다. Tailwind 기본 팔레트나 임의 hex 금지.
8. 구분은 여백으로. 장식 구분선, 그라데이션, 이모지 금지. `--line`은 차트 그리드와 게이지 눈금에만 쓴다. 센서 원의 밝기에 연동된 흰색 glow만 허용한다.

## 반드시 지킬 동작 규칙

1. 상태(연결됨, 오류, 밝기, 꺼짐)는 항상 **글자로** 표시한다. 색만으로 구분 금지.
2. 버튼, 토글 터치 영역 최소 44px. 스마트폰(375px)에서 가로 스크롤 금지.
3. 화면 상태는 `status`, `power`, `readings`다. `power`는 최신 기울기에서 계산한 `level > 0`이며 별도의 하드웨어 전원 제어를 뜻하지 않는다.
4. Supabase 키는 anon(publishable) 키만. service_role 키는 코드에 넣지 않는다.
5. 바탕은 검은색 한 테마. 텍스트 대비 4.5:1 이상.
6. 센서가 처음 연결된 직후 5초 동안 "램프를 세운 상태에서 켜야 0°가 맞습니다"를 `t-caption` `--ink-muted`로 표시한다.

## 제품 슬롯 (학생이 채우는 칸)

학생은 제품 이름, 한 줄 컨셉, 제품 설명을 `src/product.ts`의 `PRODUCT` 객체에서만 바꾼다. `ProductHeader`가 이 값을 페이지 상단과 브라우저 문서 제목에 반영한다. 값을 비워 두면 해당 슬롯의 자리표시자가 `--ink-muted`로 표시된다.

| 학생이 채우는 슬롯 | 현재 UI에 표시되는 값과 모양 | 수정 위치 |
| --- | --- | --- |
| 제품 이름 | Tilt MONO. 페이지 맨 위 `h1`, Pretendard 700, `--ink`. 브라우저 탭 제목에도 사용 | `PRODUCT.name` |
| 제품 컨셉 (한 줄) | 인터스텔라 TARS에서 온, 기울이면 켜지는 조명. 이름 바로 아래 `t-label`, `--ink` | `PRODUCT.concept` |
| 제품 설명 (2~3문장) | 기울기의 변화에 따라 LED의 밝기가 변화합니다. 세워 두면 꺼지고, 45도까지 기울일수록 밝아집니다. 컨셉 아래 `t-body`, `--ink-muted`, 최대 폭 640px | `PRODUCT.description` |
| 메인 컬러 | Tilt MONO 알루미늄 회색 `--brand: #c9cdd2`, 그 위 글자 `--on-brand: #000000` | `styles/globals.css`의 `:root` |
| 폰트 | 제품 이름은 Pretendard 700, 센서 각도 숫자는 IBM Plex Mono 600 | `--font-sans`, `--font-display` in `styles/globals.css` |

현재 제품 슬롯 값은 아래와 같다. 다른 제품으로 응용할 때는 이 세 문구를 제품에 맞게 교체하며, 센서 동작과 표시 규칙은 유지한다.

```ts
export const PRODUCT = {
	name: "Tilt MONO",
	concept: "인터스텔라 TARS에서 온, 기울이면 켜지는 조명",
	description:
		"기울기의 변화에 따라 LED의 밝기가 변화합니다. 세워 두면 꺼지고, 45도까지 기울일수록 밝아집니다.",
}
```

## 기능

| 기능 | 컴포넌트 | 데이터 |
| --- | --- | --- |
| 센서값에 따라 채워지는 흰 원 | SensorMoon | 최신 `Reading.value` |
| 센서값 게이지와 플롯 | SensorChart | 최근 60개 + 1초 간격 새 ID 조회 |
| LED 밝기 상태 | PowerToggle | 기울기 각도로 계산, 0°는 꺼짐 |
| 센서 데이터 연결, 끊기 | ConnectionControl | Supabase 조회와 폴링 시작, 중지 |
| 반응형 | AppShell | 768px 기준. 웹은 센서 원 아래 컨트롤과 게이지·차트 2열 |
| 제품 정보 | ProductHeader | `PRODUCT` |

센서값은 기울기 각도이며 단위는 도(°), 저장값은 소수일 수 있다. 화면의 숫자와 게이지 라벨은 정수로 반올림해 보여준다. 켤 때 세워 둔 자세가 0°이고, 어느 쪽으로 기울여도 양수로 커진다. 실제 범위는 0°~47° 정도다.

`SENSOR_MIN`은 0, `SENSOR_MAX`는 50, `FULL_DEG`는 45, `MAX_POINTS`는 60이다.

밝기는 `level = clamp(value / FULL_DEG, 0, 1)`로 계산한다. 0°에서 원은 윤곽선만 보이고, 45° 이상에서 흰색으로 완전히 채워진다. 같은 level이 원의 채움과 glow, LED 밝기 문구에 쓰인다.

SensorChart는 기울기 게이지(TARS처럼 기우는 사각 막대, 0°·15°·30°·45° 눈금, 0°~45° 구간 `--brand` 호)와 0°~50° 시간 그래프로 구성한다. 그래프에는 45° "최대 밝기" 점선 기준선이 있다.

"센서 연결"은 최근 `Reading` 행을 불러온 뒤 1초마다 더 큰 `id`의 새 행을 확인하는 동작이다. "연결됨"은 웹앱과 Supabase의 조회가 성공했다는 뜻이며 Arduino USB 연결 상태를 뜻하지 않는다. 웹 브라우저는 블루투스나 시리얼에 직접 연결하지 않는다. 새 센서값 전송에는 Arduino가 연결된 컴퓨터에서 `upload.py`를 실행해야 한다.

## 응용 범위

- 바꿔도 됨: 제품 슬롯, 원형 오브제 스타일, 센서 범위와 단위, 차트 포인트 수, 섹션 추가.
- 바꾸면 안 됨: 위 시각 규칙과 동작 규칙, 상태 구조, Supabase 테이블 이름과 컬럼.
